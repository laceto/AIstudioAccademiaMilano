## What was built

A single-file HTML app for retirees who want to leave a digital
heirloom of family stories. Speak (Web Speech API) or type a memory,
optionally attach a photo, fill in year/place/storyteller, and the
Archivist returns a polished `story_archive.md` and a tagged
`memory_metadata.json` ready for download. Two modes: Local (no API
key, regex polish + decade-bucketed history) and AI (Claude or OpenAI).

## Why this design

1. **Single HTML file** — the user said "Create html". A self-contained
   `index.html` deploys to GitHub Pages, Netlify, or a USB stick and
   works for a retiree without dev tooling.
2. **Two modes by default** — Local mode means the tool has real value
   day-one with zero setup, while AI mode unlocks proper historical
   lookups and richer narratives when an API key is available. No
   account, no signup, no dark-pattern paywall.
3. **Voice over typing** — the Web Speech API makes the friction-cost
   to a retiree about zero, which is the whole pitch of "weekly
   storyteller". Falls back to typing where unsupported (Safari iOS).
4. **Two output files, not one** — Markdown for humans + JSON for
   future archives. Same pattern as request 021 (micro-syllabus +
   flashcards), reused intentionally.
5. **Voice preservation as a hard constraint** — both the local-mode
   regex pass and the AI prompt explicitly strip ONLY fillers and
   stutters; idioms, dialect, and phrasing stay. The whole point is to
   sound like the storyteller, not like ChatGPT.
