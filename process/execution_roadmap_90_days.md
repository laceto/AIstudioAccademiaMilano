# Community Execution Roadmap — 90 Days

> Purpose: Operational 90-day plan for establishing AI Studio's digital and physical community presence.
> Owner Agent: Francesca (Delivery / Outreach)
> Status: active

## Phase 1 — Foundation (Days 1–14)

### Create Accounts
- GitHub organization
- LinkedIn page
- Discord server
- X account
- Reddit account
- Instagram account

### Create Branding Assets
- logo, banner, terminal visuals, AI Studio identity

### Create Core Repositories
- landing-page-template
- chatbot-template
- automation-template

## Phase 2 — Public Building (Days 15–30)

### Publish Every Day

Content types: live coding, before/after, deployed apps, AI demos

Goal: make execution visible.

## Phase 3 — Community Interaction (Days 30–60)

### Discord
Launch: AI help bot, idea intake bot, project request channel

### Reddit
Monitor: small business pain points, repetitive workflows, underserved communities

### LinkedIn
Post: real deployments, case studies, automation examples

## Phase 4 — AI Vending Prototype (Days 60–75)

Build web kiosk with: speech input, project classification, AI specification generator (Gianni), pricing engine (Marco)

## Phase 5 — Physical Layer (Days 75–90)

Atelier setup: workstation, music, screens, AI terminal, QR wall, live deployments

## KPI Targets

| Month | Target |
|---|---|
| Month 1 | 3 public builds, 10 posts, 1 real client |
| Month 2 | 10 builds, 1 recurring automation revenue, 100 community members |
| Month 3 | first AI vending workflow, first physical demo day, repeat customers |

## Long-Term Vision

AI Studio Accademia Milano becomes: local AI atelier, software factory, community node, implementation lab — where ideas are converted into deployable systems rapidly.
