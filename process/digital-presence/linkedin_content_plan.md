# LinkedIn Content Plan — AI Studio Accademia Milano

> Goal: prove the automated content pipeline works. Start smooth. Establish first-mover presence.
> Cadence: 1 post per week. Every post generated by D009 pipeline, reviewed by Luigi, published manually.
> Tone: matter-of-fact. We've been building. Now we're showing it.

---

## Post Format (every week, same structure)

```
[What was built — 1 sentence hook]

[What it does — 2-3 sentences in plain language, no jargon]

[What the client gets — 1-2 sentences on the deliverable]

[One honest observation about building it — optional but valued]

[3-5 hashtags]
```

No "excited to announce". No "leveraging AI". Just what was built and what it does.

## Rules

- Never post without Luigi's review
- Never post two days in a row (spacing matters more than frequency)
- If a post gets traction (50+ reactions), reply to every comment within 24h
- If a post generates an inbound lead, log it in `process/audit/`
