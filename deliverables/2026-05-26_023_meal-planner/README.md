# Mediterranean Weekly Meal Planner

Give it your family's favourite dishes, your favourite ingredients, and
the current season — get back a single Markdown file with a batch-cooking
7-day breakfast/dinner matrix and a categorised grocery list. Print it,
stick it to the fridge, take the list to the market.

## How it works

```
favourites + season + household ──► OpenAI gpt-4o (JSON mode) ──► schema-validated payload
                                                                              │
                                                                              ▼
                                                            Weekly_Menu_<Season>.md
                                                            ┌─────────────────────────┐
                                                            │  Section A:             │
                                                            │  7-day matrix (table)   │
                                                            │   - 2-3 breakfasts      │
                                                            │   - cook→leftover pairs │
                                                            │   - Sunday quick meal   │
                                                            │                         │
                                                            │  Section B:             │
                                                            │  Smart grocery list     │
                                                            │   🟢 Produce             │
                                                            │   🔵 Grains & Legumes    │
                                                            │   🐟 Proteins            │
                                                            │   🫒 Pantry Staples      │
                                                            └─────────────────────────┘
```

The LLM is constrained to OpenAI's `json_object` response format and a
strict schema documented in `prompts.py`. The renderer enforces:

- exactly 7 dinner entries, ordered Monday→Sunday
- every `cook` day MUST be followed by a `leftover` day with the same
  dish name; the `cook` day's `pairs_with` MUST equal the next day
- Sunday MUST be `fresh_quick` or `leftover` — never a new batch-cook
- breakfast rotation has 2 or 3 entries that cover all 7 days exactly
  once each, in contiguous blocks
- every grocery section is a list of non-empty strings

If the model returns anything malformed, `renderers.validate()` raises
before any file is written.

## Usage

```bash
# Spring/summer week for a family of 4 with their favourites
python meal_planner.py \
  --season spring_summer \
  --household 4 \
  --dishes "Pasta alla Norma" "Baked sea bass" "Lentil soup" "Frittata" \
  --ingredients "olive oil" chickpeas tomatoes zucchini ricotta walnuts

# Autumn/winter week, custom output folder
python meal_planner.py \
  --season autumn_winter \
  --household 2 \
  --out plans/winter \
  --dishes "Lentil soup" "Pumpkin risotto" "Baked cod" \
  --ingredients "olive oil" lentils farro pumpkin "cavolo nero"

# Try it without an API key — renders a deterministic sample
python meal_planner.py --season spring_summer --dry-run
```

Default output folder: `./<season>/Weekly_Menu_<Season>.md`.

## Why this is a "smart" planner, not a list of seven random dinners

1. **The rollover rule is a hard constraint, not a suggestion.** Every
   cook night is paired with a leftover night the day after, and the
   validator rejects any plan that violates that — so the LLM cannot
   silently slip back into "seven fresh dinners". Result: 3 cook
   sessions per week instead of 6-7, ~50% time saved at the stove.
2. **Cross-pollinated ingredients.** The system prompt tells the model
   to make ingredients flow between dishes (e.g. zucchini in the sea
   bass tray and again in the Sunday frittata) so nothing rots.
3. **Seasonal filter is non-negotiable.** Strawberries and zucchini in
   `spring_summer`; pumpkin and cavolo nero in `autumn_winter`. The
   prompt names the in-season produce explicitly.
4. **Mediterranean alignment.** Red meat at most once a week (preferably
   never), fish/legumes/eggs as the protein backbone, healthy fats
   (olive oil, nuts) by default.
5. **Grocery list reflects only this week's menu.** No "buy every
   condiment under the sun" — only items actually consumed by the seven
   dinners and the breakfast rotation.
